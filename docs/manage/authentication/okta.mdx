# Okta SSO <EnterpriseTag />

Enterprise workspaces can sign in with their corporate Okta identity
provider. Okta SSO supports group-based provisioning, MFA, and
centralized lifecycle management. Standard workspaces can use
[magic link](/guide/manage/authentication/magic-link) or
[Google OAuth](/guide/manage/authentication/google).

## Set it up

1. **In Okta**, create a new **OIDC Web Application** integration.
2. Set the sign-in redirect URI to `https://app.oxygen-hq.com/auth/okta/callback`.
3. Copy the **Client ID** and **Client Secret**.
4. **In Oxygen**, go to **Manage → Authentication → Okta**.
5. Paste the Client ID, Client Secret, and your Okta domain
   (e.g. `acme.okta.com`). Save.
6. Test the flow from an incognito window: clicking **Sign in with Okta**
   on `app.oxygen-hq.com` should redirect through Okta and back into your
   workspace.

## What admins control

- Which Okta groups can sign in (configured in Okta).
- Which Oxygen role new users land in (configured in
  **Manage → Authentication → Defaults**).
- Whether magic link sign-in stays enabled alongside Okta as a fallback.
