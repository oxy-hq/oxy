The Oxygen MCP server runs as part of Oxygen Cloud at
`https://api.oxy.tech/mcp` and exposes Oxygen's capabilities as
discrete tools an MCP client (Claude Desktop, Cursor, etc.) can
invoke.

This section documents every tool's name, parameters, and example
invocation. Pair it with the
[MCP integration guide](/build/embed-extend/mcp) for setup.
